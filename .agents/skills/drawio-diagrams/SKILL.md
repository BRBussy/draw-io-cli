# draw.io diagrams for Codex

Before working on a diagram, read and follow
[the shared drawio-cli workflow](../../../skills/drawio-diagrams/SKILL.md).
Resolve that path relative to this file. The shared skill directory is
`skills/drawio-diagrams/`, two levels below the repository root containing
`src/cli.js`. Use that root for CLI commands, even when the working directory
is elsewhere. The shared workflow contains the editing constraints,
prerequisite diagnostics, rendering commands and verification requirements.
